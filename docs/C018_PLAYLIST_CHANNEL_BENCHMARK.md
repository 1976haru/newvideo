## 검증된 사실과 미검증 사항

**확인됨:** 공식 영상의 테마·용도 설명, 선곡/창작자 크레딧, YouTube가 설명한 캐릭터형 루프, Relaxation Film 제작자가 밝힌 자체촬영+구매 영상 활용.

**미확인:** 채널별 모든 원본의 실제 촬영 해상도/편집 방식/원본 길이, 유튜브 업로드 영상의 다운로드 권한, 음악·아트워크 재사용 허가, 영상별 저작권 제3자 권리, 조회수가 발생한 인과관계, Cafe Music BGM 특정 영상의 배경 소재·모션 구현.

**제작 방식 구분:** 계절별 음악+아트워크 편집 / 일상 상황별 BGM / 캐릭터 애니메이션 루프 / 실제 촬영 또는 적법 라이선스 확보 풍경+음악. 동영상 제목에 4K가 포함돼도 개별 원본 클립의 실제 해상도를 증명하지 않는다.

## V2 기능 적용 및 우선순위

1. **P0 자연풍경형**: 180초 이상 원본의 출처·실파일 길이·해상도가 확인된 경우에만 장편원본 탭에 표시. 길이 확인 불가, 3분 미만은 '없음/확인 불가'로 알리고 짧은 클립을 자동 대체하지 않음.
2. **P1 계절형 태그**: 봄/여름/가을/겨울, 벚꽃/단풍/첫눈/크리스마스 분위기, 시간대 구분. 출처가 알려지지 않은 추정 태그는 '미확인' 상태로 저장.
3. **P1 일상형 태그**: 아침카페, 호숫가 산책, 비, 노을, 고정 구도 및 산책 장면 구분. 고정 70%·산책 30%는 후속 Composer의 기본 프리셋이지 검색 검증 대체가 아님.
4. **P3/후속 캐릭터형**: 자체 제작 오리지널 이미지/애니메이션만 사용. 자연풍경 실사 검색과 엄격 분리.
5. **R4/R5 플레이리스트 출력**: 사용자 선택·권리 검토 완료 영상만 조합, FFmpeg/ffprobe 결과 검증. 3/10/20/30/60분 출력과 15곡 시작 시 12초간 '01. 제목' SRT 후속 통합.

## 권리·다운로드 정책

- 벤치마킹은 **영감·기능 요구 연구**일 뿐이다. 원본 YouTube 영상을 무단 다운로드/재가공하거나 그 음악·캐릭터·영상 일부를 사용자 유튜브에 재업로드하지 않는다.
- Chillhop/Lofi Girl의 아트워크 담당자 크레딧은 저작물 재사용 허가와 다르다. BGMC 매장 음악 서비스 역시 제3자의 유튜브 상업적 사용 승인과 다르다.
- Relaxation Film이 구매한 영상의 사용권은 그 채널의 권한에 관한 설명일 뿐, Nature Video Studio 사용자에게 영상이 무료/CC0라고 입증하지 않는다.
- 개별 자연영상은 공식 제공처 API와 허용된 방식만 사용한다. 원본 URL, 제작자, 라이선스 URL/버전, 확인 시각, 실파일 해상도, 180초 검증, SHA256, 사람이 승인한 권리 기록을 보존한다. NC·ND·권리 불명은 상업 제작 기본 차단.
- 채널 분석 자료는 검색 후보 소스가 아니다. V2 검색 후보는 Wikimedia Commons/Internet Archive 등 출처·권리 검증이 가능한 개별 원본으로부터 얻는다.

## C018 수용 판정 및 실행 증거

- 사용자 체크리스트상 **완료 2/2점**이며 대표 원본은 [Chillhop Fall 2026](https://www.youtube.com/watch?v=dYuNh58nLt8).
- 실제 공개 페이지를 조사해 원본 4유형 대표 영상/공식 자료를 대조했음. 실제 시청 현장의 전체 영상 장면/편집 프레임을 포렌식 분석했다고 주장하지 않음.
- GitHub feature 브랜치에 **문서만** 추가하고 V1/V2 코드·사용자 DB·API 키·미디어·main은 변경하지 않음. 신규 코드 테스트는 문서 변경에 해당 없음. CI 실행 상태는 별도 검증.
- C018 완료는 **유형·관찰 근거·적용 구분**에 대한 완료이며, R1 검색·R2 재생·R4 영상 편집 완성을 뜻하지 않는다.
